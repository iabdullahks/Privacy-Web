# Lovable Prompt – Champion Cargo LLC Website (Frontend Only)

Create a **modern, premium, responsive frontend website** for **Champion Cargo LLC**, a professional logistics and transportation company. This is **frontend only**—do **not** create any backend, database, authentication, admin panel, APIs, CMS, forms processing, or server-side functionality. Any forms should be UI-only with validation and placeholder success states.

## Objective

The primary goal is to create a trustworthy, corporate website where the **Privacy Policy page is the most important page**. The website should communicate professionalism, security, transparency, and compliance.

## Technology Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Framer Motion
* Lucide React Icons
* Fully Responsive
* SEO-ready frontend
* Accessibility (WCAG)

## Design Style

Design a premium corporate logistics website.

Use:

* White background
* Navy Blue (#0F2D52)
* Gold accents (#D4AF37)
* Light Gray sections
* Dark text (#1F2937)
* Plenty of whitespace
* Rounded corners (16–20px)
* Soft shadows
* Smooth hover animations
* Clean typography
* Elegant micro-interactions

The design should look like a high-end logistics company, not a generic trucking website.
